# แดชบอร์ดดอกไม้จันทน์ — โรงพยาบาลสันทราย

ไฟล์: `index.html` `poster.jpg` `bg.webm` `bg.mp4` (หน้าเว็บ static) · `Code.gs` (backend)

## ติดตั้ง (ต้องทำ 1 ครั้ง)
1. Apps Script เดิม → วาง `Code.gs` ใหม่ทั้งไฟล์ → Deploy → Manage deployments → Edit → Version: **New version** → Deploy (URL /exec เดิมใช้ต่อได้)
   - ถ้ายังไม่เคย Run `setup` ให้รันก่อน 1 ครั้ง
2. push `index.html` `poster.jpg` `bg.webm` `bg.mp4` ขึ้น repo → Vercel (ต้องมีครบทุกไฟล์)

## การอัปเดตยอดโดยแอดมิน
- เปิดเว็บ → ลิงก์เล็ก ๆ “สำหรับผู้ดูแลระบบ” ท้ายหน้า (หรือเปิด `...เว็บ/#admin`) → ใส่รหัส
- แท็บ “อัปเดตยอด”: บันทึกยอดรายวัน (วันที่ซ้ำ = แก้ไข), ตั้งยอดรวมเอง, แก้/ลบรายการ
- แท็บ “ตั้งค่าเป้าหมาย”: เป้าหมาย (ดอก) และกำหนดเวลา
- แท็บ “ความคิดเห็น”: อนุมัติ/ลบความคิดเห็นที่รออนุมัติ
- รหัสผ่านถูกตรวจที่ `Code.gs` เท่านั้น ไม่อยู่ใน index.html · ผิด 5 ครั้งล็อก 10 นาที · ล็อกอินอยู่ได้ 2 ชั่วโมง
- เปลี่ยนรหัส: Apps Script → Project Settings → Script properties → เพิ่ม `ADMIN_PASSWORD` (ค่านี้ใช้แทนค่าในโค้ด) แล้วลบรหัสออกจาก `Code.gs`

## พื้นหลังเคลื่อนไหว
วิดีโอ sandalwood_memorial_animated_bg แปลงเป็น H.264/WebM แล้ววางเป็นพื้นหลังฟุ้งมืด (blur) ทั้งเว็บ มีละอองทองลอยทับ ตอบสนองการเลื่อนและเมาส์ ปิดอัตโนมัติถ้าเครื่องตั้งค่าลดการเคลื่อนไหว
